# Changelog

All notable changes to this project are documented here. Versions follow [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-10-03

First release.

- Frameless glass widget with acrylic blur (Windows 11) or blur (Windows 10), in dark, light, or matching the Windows theme, with three glass levels.
- Sits on the desktop layer and stays visible on Show desktop (Win+D). Can also be set to Always on top. Position can be locked.
- Sign in with your Google account in the browser (OAuth with PKCE). The token is encrypted with Windows DPAPI.
- View all lists grouped, or a single list. Subtasks are shown under their parent.
- Filter by Today, Upcoming, Overdue or No date. Search titles and notes. Sort by your order or by due date.
- Complete, add, rename (double-click), add subtasks, set due dates with quick picks or a calendar, edit notes, delete with undo, and create lists.
- Changes show immediately and sync in the background. Tasks are cached for instant start and offline viewing.
- Tray icon, single instance, Start with Windows, auto-refresh interval, resize from any edge.
- Installer (per-user, no admin rights needed) and a portable zip.
